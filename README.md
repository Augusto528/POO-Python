# Restaurant Simulation in Python

A small restaurant-system simulation developed in Python to practice object-oriented programming and the use of classes to represent application data and behavior.

## Overview

This project applies class-based organization to a simplified restaurant scenario. It was developed as an academic programming exercise and demonstrates how object-oriented structures can be used to model parts of a real-world system.

## Concepts

- Python programming
- Classes and objects
- Object-oriented programming (OOP)
- Modeling entities and their behavior
- Organizing program logic into classes

## Repository Structure

- `Codigo/` — contains the project's source code.

## Requirements

- Python 3

No additional dependencies are documented in the repository overview. If the source code imports external packages, install those packages before running the application.

## Running the Project

1. Clone or download this repository.
2. Open the `Codigo/` directory and identify the main Python file.
3. Run that file with Python 3 from a terminal. For example:

   ```bash
   python main.py
   ```

   Replace `main.py` with the actual entry-point filename if it differs.

## Project Context

This repository is intended to demonstrate foundational programming and object-oriented design concepts in a practical, restaurant-themed example.
